Operating loop

Design → Fabricate → Measure → Model → Deploy

AI를 장식 문구로 쓰지 않고, 실험 전후 설계 공간을 좁히는 연구실 운영 루프로 제시합니다. 학생은 제작·측정·모델링을 하나의 파이프라인으로 경험합니다.

  1. Design

    문헌·물성·해양환경 조건으로 후보 소재와 소자 구조를 정의합니다.

  2. Fabricate

    TENG, 나노섬유, 코어-쉘, 2D 소재 기반 소자를 제작합니다.

  3. Measure

    전기 출력, 감도, 습도 안정성, 생체/환경 응답을 측정합니다.

  4. Model

    LBM-DPM 및 데이터 기반 모델로 설계 공간을 압축합니다.

  5. Deploy

    해양·헬스케어·환경 모니터링 시나리오로 검증합니다.
