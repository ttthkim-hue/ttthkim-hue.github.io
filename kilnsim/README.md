# KilnSim 3D Control Room public demo

Proposal-grade interactive visualization for KILN_AI_CEMENT_DT.

- orbit / zoom / pan 3D kiln
- camera fly-to zones
- axial-cell picking and scrubber
- thermal, shell, bed and cell-grid layers
- scenario sliders for fuel/feed/speed sensitivity illustration
- axial temperature chart and per-cell detail

Safety: public visualization only. No PLC/DCS write path. Plant validation is NOT_STARTED.
The client-side slider response is a bounded visualization surrogate, not a validated plant prediction.
